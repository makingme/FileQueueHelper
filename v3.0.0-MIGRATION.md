# FileQueueHelper v3.0.0 마이그레이션 가이드

## 개요

v3.0.0은 **파티션 개념을 완전히 제거**한 메이저 버전입니다. 코드 구조를 단순하고 심플하게 만들기 위해 Breaking Changes를 도입했습니다.

## 주요 변경사항

### 1. 파티션 개념 완전 제거

**v2.x**에서는 멀티 파티션 기반 큐 시스템을 제공했으나, **v3.0.0**부터는 **단일 큐** 방식으로 전환되었습니다.

- ❌ **제거된 개념**: Partition (파티션)
- ✅ **새로운 개념**: Single Queue (단일 큐)

### 2. 핵심 클래스 변경

| v2.x | v3.0.0 | 변경 사유 |
|------|--------|----------|
| `PartitionManager` | `QueueManager` | 단일 큐 관리로 단순화 |
| `PartitionContext` | `QueueContext` | 파티션 개념 제거 |
| `PartitionSummaryVo` | `QueueSummaryVo` | 단일 큐 요약 정보 |
| `Contents.DEFAULT_PARTITION` | (제거) | 기본 파티션 상수 불필요 |

### 3. 삭제된 파일들

```
src/main/java/com/queue/file/controller/PartitionManager.java
src/main/java/com/queue/file/vo/PartitionContext.java
src/main/java/com/queue/file/vo/PartitionSummaryVo.java
src/test/java/com/queue/file/controller/PartitionManagerTest.java
src/test/java/com/queue/file/SeparatePartitionFilesTest.java
```

## 마이그레이션 예제

### 예제 1: 기본 Write/Read

**v2.x:**
```java
BaseController controller = ControllerFactory.create("queue.mv");

// 파티션 지정 write
controller.write("P1", "myExecutor", "data");

// 파티션 지정 read
FileQueueData data = controller.read("P1", "myExecutor");

// 파티션 지정 commit
controller.readCommit("P1", "myExecutor");
```

**v3.0.0:**
```java
BaseController controller = ControllerFactory.create("queue.mv");

// partition 파라미터 제거
controller.write("", "myExecutor", "data");

// partition 파라미터 제거
FileQueueData data = controller.read("myExecutor");

// partition 파라미터 제거
controller.readCommit("myExecutor");
```

### 예제 2: Bulk Operations

**v2.x:**
```java
List<String> dataList = Arrays.asList("d1", "d2", "d3");
controller.writeBulk("P1", "exec", dataList);

List<FileQueueData> result = controller.read("P1", "exec", 10);
controller.readCommit("P1", "exec");
```

**v3.0.0:**
```java
List<String> dataList = Arrays.asList("d1", "d2", "d3");
controller.writeBulk("", "exec", dataList);

List<FileQueueData> result = controller.read("exec", 10);
controller.readCommit("exec");
```

### 예제 3: Management Operations

**v2.x:**
```java
// 파티션 목록 조회
Set<String> partitions = controller.getAllPartitionNameSet();

// 특정 파티션 요약 정보
Map<String, PartitionSummaryVo> summary = controller.getSummaryInfo();
int dataCount = summary.get("P1").getDataCount();

// 특정 파티션 데이터 조회
List<FileQueueData> dataList = controller.getPartitionDataList("P1");

// 특정 파티션 데이터 삭제
controller.clearData("P1");
```

**v3.0.0:**
```java
// 파티션 개념 제거 - getAllPartitionNameSet() 삭제됨

// 단일 큐 요약 정보
QueueSummaryVo summary = controller.getSummaryInfo();
int dataCount = summary.getDataCount();

// 큐 데이터 조회
List<FileQueueData> dataList = controller.getDataList();

// 큐 데이터 삭제
controller.clearData();
```

## 이점

### 1. 코드 단순화
- **DataAccess**: 664줄 → 477줄 (28% 감소)
- **StatsTracker**: 74줄 → 65줄 (12% 감소)
- **BaseController**: API 메서드 수 감소

### 2. 성능 개선
- 파티션 그룹핑 로직 제거로 write 성능 향상
- 2-tier 락 → 단일 write lock으로 read 성능 향상
- 멀티 파티션 락 획득 오버헤드 제거

### 3. 유지보수성 향상
- 단일 큐 방식으로 코드 이해도 향상
- 파티션 관련 복잡도 제거
- 테스트 코드 단순화
